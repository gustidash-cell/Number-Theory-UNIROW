Media Pembelajaran Interaktif Modul Teori Bilangan (PMA4108) berbasis HTML/CSS/JS modern untuk Mahasiswa Program Studi Pendidikan Matematika, Universitas PGRI Ronggolawe (UNIROW) Tuban.

## ✨ Fitur Utama
- 🌐 **Fitur Multibahasa**: Pilihan bahasa Indonesia 🇮🇩, English 🇬🇧, dan Melayu 🇲🇾.
- 🌙 **Dark & Light Mode Toggle**: Pengubah tema warna terang dan gelap.
- 📐 **Format Matematika KaTeX**: Notasi dan simbol matematika jernih.
- 📜 **Kartu Struktur Deduktif**: Format visual khusus untuk Definisi, Postulat, Teorema, Lema, Akibat, Bukti ($\blacksquare$), dan Contoh.
- 📱 **Desain Responsif**: Tampilan rapi di Smartphone, Tablet, dan Komputer.

## 📁 Struktur Berkas
- `index.html` - Modul utama interaktif
- `Modul_Teori_Bilangan_Pertemuan_1-3.html` - Berkas modul lengkap Pertemuan 1–3
- `README.md` - Dokumentasi repository

## 🚀 Cara Menggunakan
1. **Online**: Klik link **[Buka Modul Interaktif](https://gustidash-cell.github.io/Number-Theory-UNIROW/)** di atas.
2. **Offline**: Cukup buka file `index.html` langsung di browser web Anda.
