Sifat-sifat Keterbagian & Algoritma Pembagian

Pertemuan 3  ·  Sub-CPMK 1.3  ·  Rosen (2011), Section 1.5

Tujuan Pertemuan

Mahasiswa mampu mendefinisikan relasi keterbagian pada bilangan bulat, membuktikan sifat-sifat dasarnya secara deduktif, serta menyatakan dan membuktikan Algoritma Pembagian (Division Algorithm) menggunakan Prinsip Terurut Rapi yang telah diperkenalkan pada Pertemuan 1.

1. Relasi Keterbagian

Sebelum masuk ke bilangan prima dan FPB pada pertemuan-pertemuan berikutnya, perlu dibangun terlebih dahulu bahasa dasar untuk membicarakan hubungan antar bilangan bulat, yaitu relasi keterbagian (divisibility).

Definisi 3.1 (Keterbagian)

Misalkan a, b ∈ ℤ dengan a ≠ 0. Dikatakan a habis membagi b, ditulis a ∣ b, jika terdapat bilangan bulat c sedemikian sehingga b = ac.

Jika a tidak habis membagi b, ditulis a ∤ b. Bilangan a disebut pembagi (divisor) dari b, dan b disebut kelipatan (multiple) dari a.

Contoh 3.1

3 ∣ 12 karena 12 = 3 · 4. Sebaliknya, 5 ∤ 12 karena tidak ada bilangan bulat c yang memenuhi 12 = 5c. Perhatikan pula bahwa untuk setiap a ≠ 0, berlaku a ∣ 0, sebab 0 = a · 0.

Relasi ini tampak sederhana, namun sifat-sifatnya menjadi fondasi untuk hampir seluruh materi berikutnya, mulai dari bilangan prima hingga kongruensi. Empat sifat berikut adalah yang paling sering digunakan sebagai alat pembuktian.

Teorema 3.1 (Sifat-sifat Dasar Keterbagian)

Untuk sembarang a, b, c ∈ ℤ, berlaku:

(a) Jika a ∣ b dan b ∣ c, maka a ∣ c  (sifat transitif).

(b) Jika a ∣ b dan a ∣ c, maka a ∣ (bx + cy) untuk sembarang x, y ∈ ℤ  (sifat kombinasi linear).

(c) Jika a ∣ b dan b ≠ 0, maka |a| ≤ |b|.

(d) Jika a ∣ b dan b ∣ a, maka a = ±b.

Bukti (a)

Karena a ∣ b, terdapat k ∈ ℤ dengan b = ak. Karena b ∣ c, terdapat m ∈ ℤ dengan c = bm. Substitusi memberi c = (ak)m = a(km). Karena km ∈ ℤ, maka menurut Definisi 3.1, a ∣ c.∎

Bukti (b)

Karena a ∣ b dan a ∣ c, terdapat k, m ∈ ℤ dengan b = ak dan c = am. Untuk sembarang x, y ∈ ℤ:

bx + cy = (ak)x + (am)y = a(kx + my).

Karena kx + my ∈ ℤ, maka a ∣ (bx + cy).∎

Bukti (c)

Karena a ∣ b, terdapat k ∈ ℤ dengan b = ak. Karena b ≠ 0, maka k ≠ 0, sehingga |k| ≥ 1. Akibatnya |b| = |a| · |k| ≥ |a| · 1 = |a|.∎

Bukti (d)

Jika a = 0, maka dari a ∣ b diperoleh b = 0, sehingga a = b = 0 dan pernyataan terpenuhi. Andaikan a, b ≠ 0. Berdasarkan sifat (c), a ∣ b memberi |a| ≤ |b|, dan b ∣ a memberi |b| ≤ |a|. Dari kedua pertidaksamaan ini diperoleh |a| = |b|, yang berarti a = b atau a = −b, yaitu a = ±b.∎

Contoh 3.2 (Penerapan Sifat Kombinasi Linear)

Misalkan a ∣ b dan a ∣ (b + 2). Tunjukkan bahwa a ∣ 2.

Penyelesaian

Berdasarkan Teorema 3.1(b), karena a ∣ (b + 2) dan a ∣ b, maka a membagi kombinasi linear 1 · (b + 2) + (−1) · b = 2. Jadi a ∣ 2.∎

2. Algoritma Pembagian

Tidak semua pasangan bilangan bulat memenuhi relasi keterbagian secara eksak. Jika b tidak habis dibagi a, tetap ada cara sistematis untuk menyatakan b dalam bentuk kelipatan a ditambah suatu sisa. Fakta inilah yang dijamin oleh Algoritma Pembagian, yang sesungguhnya bukan sebuah "algoritma" dalam arti prosedural, melainkan teorema eksistensi dan ketunggalan.

Teorema 3.2 (Algoritma Pembagian / Division Algorithm)

Untuk sembarang a ∈ ℤ dan b ∈ ℤ⁺, terdapat dengan tunggal bilangan bulat q dan r sedemikian sehingga

a = bq + r,    0 ≤ r < b.

Bilangan q disebut hasil bagi (quotient) dan r disebut sisa (remainder).

Bukti Eksistensi

Tinjau himpunan S = {a − bk : k ∈ ℤ, a − bk ≥ 0}. Himpunan S tidak kosong: dengan memilih k yang cukup kecil (misalnya k = −|a|), diperoleh a − bk ≥ 0, sehingga elemen tersebut berada di S.

Karena S ⊆ ℤ⁺ ∪ {0} tidak kosong, menurut Prinsip Terurut Rapi (Postulat 1.1, diperluas mencakup 0), S memiliki elemen terkecil. Sebut elemen ini r = a − bq untuk suatu q ∈ ℤ, sehingga a = bq + r dengan r ≥ 0.

Akan ditunjukkan r < b. Andaikan sebaliknya, r ≥ b. Maka r − b ≥ 0, dan

r − b = (a − bq) − b = a − b(q+1),

sehingga r − b juga berbentuk a − bk dengan k = q+1, dan r − b ≥ 0 berarti r − b ∈ S. Namun r − b < r (karena b > 0), bertentangan dengan r sebagai elemen terkecil dari S. Jadi pengandaian salah, sehingga r < b.∎

Bukti Ketunggalan

Andaikan terdapat dua pasang q₁, r₁ dan q₂, r₂ yang sama-sama memenuhi a = bq₁ + r₁ = bq₂ + r₂ dengan 0 ≤ r₁, r₂ < b.

Dari kesamaan tersebut diperoleh b(q₁ − q₂) = r₂ − r₁, sehingga b ∣ (r₂ − r₁). Karena 0 ≤ r₁, r₂ < b, selisih r₂ − r₁ memenuhi −b < r₂ − r₁ < b. Satu-satunya kelipatan b pada rentang tersebut adalah 0, sehingga r₂ − r₁ = 0, yaitu r₁ = r₂.

Karena r₁ = r₂ dan b > 0, dari b(q₁ − q₂) = 0 diperoleh q₁ = q₂. Jadi pasangan (q, r) tunggal.∎

Akibat 3.1

Untuk b = 2, Algoritma Pembagian menjamin setiap bilangan bulat a dapat ditulis sebagai a = 2q atau a = 2q + 1 — yaitu, setiap bilangan bulat pasti genap atau ganjil, tidak keduanya sekaligus. Fakta yang biasa dianggap "jelas dengan sendirinya" sejak sekolah dasar ini ternyata merupakan kasus khusus dari Teorema 3.2.

Contoh 3.3

Tentukan hasil bagi q dan sisa r dari pembagian a = −53 oleh b = 7.

Penyelesaian

Perlu dicari q sehingga 0 ≤ −53 − 7q < 7. Karena −53/7 ≈ −7,57, kelipatan 7 yang tepat berada di bawah −53 adalah 7 · (−8) = −56. Maka q = −8, dan r = −53 − 7(−8) = −53 + 56 = 3.

Jadi −53 = 7 · (−8) + 3, dengan 0 ≤ 3 < 7. Perhatikan bahwa q = −7 tidak memenuhi, sebab akan memberi r = −53 − 7(−7) = −4, yang negatif dan melanggar syarat 0 ≤ r < b.∎

3. Kaitan dengan Materi Berikutnya

Algoritma Pembagian bukan sekadar prosedur aritmetika biasa. Ia menjadi mesin pembuktian utama pada Pertemuan 6 dan 7, ketika Algoritma Euclid — yang secara berulang menerapkan Teorema 3.2 — digunakan untuk menghitung Pembagi Persekutuan Terbesar (FPB) dan membuktikan Identitas Bézout. Sifat kombinasi linear pada Teorema 3.1(b) juga akan muncul kembali secara berulang, khususnya dalam pembuktian sifat-sifat kongruensi pada Pertemuan 11.

Latihan Soal

  1. Buktikan bahwa jika a ∣ b dan c ∣ d, maka ac ∣ bd.
  2. Misalkan n ∈ ℤ⁺. Buktikan bahwa (n − 1) ∣ (n² − 1) untuk semua n ≥ 2.
  3. Tentukan hasil bagi dan sisa dari pembagian a = 100 oleh b = 13, serta dari a = −100 oleh b = 13. Bandingkan kedua hasil dan jelaskan mengapa sisanya sama sedangkan hasil baginya berbeda tanda.
  4. Buktikan bahwa jika a ∣ (b + c) dan a ∣ b, maka a ∣ c.
  5. Gunakan Algoritma Pembagian dengan b = 3 untuk menunjukkan bahwa setiap bilangan bulat n dapat dinyatakan dalam salah satu bentuk 3k, 3k+1, atau 3k+2. Gunakan hasil ini untuk membuktikan bahwa n² selalu berbentuk 3m atau 3m+1, tidak pernah 3m+2.

Pertanyaan Pemahaman

  1. Mengapa Definisi 3.1 mensyaratkan a ≠ 0? Apa yang salah jika a = 0 diperbolehkan dalam relasi a ∣ b?
  2. Pada bukti eksistensi Teorema 3.2, di bagian mana Prinsip Terurut Rapi (Postulat 1.1) benar-benar digunakan, dan mengapa langkah tersebut tidak bisa digantikan hanya dengan argumen "jelas secara intuitif"?
  3. Jelaskan mengapa syarat 0 ≤ r < b (bukan, misalnya, −b < r ≤ 0) penting untuk menjamin ketunggalan pasangan (q, r).
